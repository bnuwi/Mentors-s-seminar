## Структура репозитория

### from_seminars
В данной папке находятся задания, выполненные в рамках семинарских занятий.  
Каждая поддиректория соответствует отдельному семинару и содержит решения задач, разобранных на занятиях.

### pytest_example_*
В этой папке представлены примеры работы с библиотекой **pytest**:
- написание тестов
- запуск тестов
- использование базовых возможностей pytest

### go_homework
Практические задания на языке **Go**
Каждое задание находится в отдельной папке:

| № | Папка | Задание |
|---|-------|---------|
| 1 | `task01_calc` | Калькулятор с проверкой деления на ноль |
| 2 | `task02_...` | Анализ числа: знак, чётность, делимость на 3 и 5 |
| 3 | `task03_...` | Сумма и среднее от 1 до N |
| 4 | `task04_...` | Таблица умножения через функцию `printTable(n)` |
| 5 | `task05_...` | Максимум и минимум из N чисел |
| 6 | `task06_...` | Количество положительных, отрицательных чисел и нулей |
| 7 | `task07_...` | Сумма чётных чисел от 1 до N, делящихся на 3 |
| 8 | `task08_...` | Проверка простого числа, функция `isPrime(n int) bool` |
| 9 | `task09_...` | Мини-банкомат: просмотр баланса, пополнение, снятие |
| 10 | `task10_stat` | Статистика последовательности |

**Запуск** (нужен Go 1.22 или новее):

```bash
go run ./task1_calc
```

Программы читают ввод с клавиатуры: введите значение и нажмите Enter.
